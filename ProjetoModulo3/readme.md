# 🌎 Copa do Mundo 2026

Projeto desenvolvido como atividade prática utilizando HTML, CSS, JavaScript e JSON para exibir informações das seleções participantes da Copa do Mundo de 2026.

---

## 📌 Objetivo do projeto

O objetivo deste projeto foi desenvolver uma aplicação web interativa capaz de exibir informações detalhadas sobre as seleções participantes da Copa do Mundo 2026 de forma organizada, dinâmica e visualmente agradável.

O sistema foi desenvolvido utilizando tecnologias front-end, consumindo dados externos através de um arquivo JSON.

---

## 🚀 Funcionalidades

O site possui as seguintes funcionalidades:

✅ Exibição das 48 seleções participantes da Copa do Mundo 2026

✅ Menu lateral contendo a lista das seleções

✅ Exibição dinâmica dos dados da seleção escolhida

✅ Informações detalhadas dos jogadores:

- Nome
- Clube atual
- Idade
- Cidade de nascimento

✅ Exibição do técnico da seleção

✅ Botão de retorno à lista principal

✅ Fundo personalizado em estilo Copa do Mundo

✅ Layout responsivo
