# 🌎 Copa do Mundo 2026

Projeto desenvolvido como atividade prática utilizando HTML, CSS, JavaScript e integração com API-Football (API-Sports) para exibir informações reais das seleções participantes da Copa do Mundo de 2026.

---

## 📌 Objetivo do projeto

O objetivo deste projeto foi desenvolver uma aplicação web interativa capaz de exibir informações detalhadas das seleções participantes da Copa do Mundo de 2026 de forma organizada, dinâmica e visualmente agradável.

O sistema foi desenvolvido utilizando tecnologias front-end modernas e integração com APIs externas, permitindo trabalhar com dados reais e atualizados em tempo real.

---

## 🚀 Funcionalidades

O site possui atualmente as seguintes funcionalidades:

✅ Exibição das seleções participantes

✅ Menu lateral contendo a lista das seleções

✅ Campo de pesquisa das seleções

✅ Filtro por continente

✅ Sistema de favoritos ⭐

✅ Alternância entre tema claro/escuro

✅ Exibição dinâmica da seleção escolhida

✅ Consumo de dados reais através da API-Football (API-Sports)

✅ Exibição de jogadores reais da seleção

✅ Fotos reais dos jogadores

✅ Informações dos jogadores:

- Nome
- Idade
- Número
- Posição

✅ Badge visual indicando posição do jogador

✅ Perfil individual do jogador ao clicar no card

✅ Modal com:

- Foto do jogador
- Bandeira da seleção
- Nome
- Idade
- Número
- Posição
- Informações da seleção

✅ Cards modernos em estilo escuro/neon

✅ Fundo personalizado em estilo Copa do Mundo

✅ Layout responsivo

## 📖 Considerações finais

Este projeto foi desenvolvido para prática de conceitos fundamentais de desenvolvimento web, integração com APIs, manipulação de dados dinâmicos e construção de interfaces modernas utilizando HTML, CSS e JavaScript.

Além dos conhecimentos técnicos, o projeto contribuiu para o desenvolvimento de habilidades relacionadas à lógica de programação, integração de APIs, organização de dados e publicação de aplicações web.

Todos os dados do projeto utilizam fontes reais através da API-Football (API-Sports), evitando dados simulados ou fictícios.
